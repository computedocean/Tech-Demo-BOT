# Liquid Glass Orb

A single-page playground for the [ReactDrops Liquid Glass Orb](https://reactdrops.dev/components/ai/liquid-glass-orb). It cycles AI agent states and exposes palette, speed, distortion, and the thinking pattern. Auto demo drives a synthetic voice envelope, so no microphone is required.

## Run

From this folder:

```bash
bun install
bun run dev
```

Production build:

```bash
bun run build
bun run preview
```
