# ConnectOnion switchboard

Unofficial single-user panel for ConnectOnion’s preview-then-apply idea. It runs with no `co` binary, Python, Chrome, or secrets. Preview changes nothing. Apply writes only inside `sandbox/.runtime`. Email never sends.

```bash
bun install
bun run dev
```
