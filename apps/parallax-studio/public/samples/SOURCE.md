# Bundled sample media

These files are original synthetic media made for this lab. They are bundled samples, not output from an image, video, or audio model.

| File | What it is | License |
| --- | --- | --- |
| `harbor-still.svg` | Hand-authored vector still of a geometric harbor | CC0 1.0 |
| `harbor-still.png` | Raster of that SVG | CC0 1.0 |
| `harbor-reel.mp4` | Two-second silent push derived from the still with ffmpeg | CC0 1.0 |
| `harbor-tone.wav` | Two-second tone synthesized in code (sine partials, no sample library) | CC0 1.0 |

CC0 1.0 Universal: https://creativecommons.org/publicdomain/zero/1.0/

No third-party stock, no upstream Parallax media, and no commercial studio assets.
