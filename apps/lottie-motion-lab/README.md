# Lottie motion lab

A single-user playground for three hand-built motion patterns. Pick a personality (playful, calm, or sharp), press Play, then edit the duration or easing and replay.

```bash
bun install
bun run dev
bun test
```

Independent demo. Not an official LottieFiles product and not a skill runner. Timing ideas are adapted from [motion-design-skill](https://github.com/LottieFiles/motion-design-skill) (MIT).
